# Managing Prompts

System prompts define the behavior and personality of your agents. A well-crafted prompt tells the agent who it is, what it should do, and how it should respond.

## Creating a Prompt

1. Navigate to **Prompts** in the sidebar.
2. Click **Create Prompt**.
3. Enter a name for the prompt (use something descriptive, e.g., "Customer Support Agent").
4. Write the system prompt content in the text area.
5. Click **Save**.

## Tips for Writing System Prompts

- **Be specific** about the agent's role and responsibilities.
- **Define boundaries** — state what the agent should and shouldn't do.
- **Include formatting instructions** if you want structured output (e.g., markdown, bullet points).
- **Mention available tools** if the agent has access to any.
- **Set the tone** — formal, friendly, technical, etc.

## Editing and Deleting Prompts

- Click a prompt card to open it for editing. Changes are saved when you click **Save**.
- Delete prompts you no longer need. Agents using a deleted prompt will need to be updated with a new prompt before they can function.
